Material issues and evaluation limits

Motion Studio 2.1.0: preview editing left navigation stuck until reload; Apply showed a subscription gate. These editor issues were not observed in production.

Remotion: synthetic Next→Back clicks in one JavaScript task went one stop too far. Ordinary separate-event interruption passed. Inspector default-prop edits auto-save source; the reviewer undid the audit edit and verified a clean tree.

Coverage was desktop Chromium at 320, 390, 768, 960, and 1280px. Reduced motion used controlled browser simulation. Other browsers, physical touch, screen readers, enlarged/localized copy, video export, and performance/leak benchmarking remain unverified.
