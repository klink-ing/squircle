The caps stay circular arcs. amt sets how much of each cap is handed to the easing — 1 is a bare semicircle, identical to border-radius: 9999px and only G1. ease smooths that join further along the flat edge without spending more of the arc, so raising it lets the amount come back down. 0, the lowest, is a clothoid. When the element is too narrow for the request, both are eased down together so the curvature rate stays put; a square has no flat edge at all and renders as a plain circle.

For the shipped easing next to a CAD-style curvature-continuous fillet, with curvature combs, see the website's /demos/pill-algorithms page (vp dev in website/).

Backgrounds, Borders & Shadows

The shape is a mask, so the element keeps its own background and that background gets pill-shaped. A border is set with the pill's own properties — they drive a real border too, which is what shows without the worklet and what reserves the room the drawn ring grows back into. The stadium radius stays under the mask, so native box-shadow: inset and a negative-offset outline just work; only what is painted outside the box needs a wrapper.
