The caps stay circular arcs. amt sets how much of each cap is handed to the easing — 1 is a bare semicircle, identical to border-radius: 9999px and only G1. spread smooths that join further along the flat edge without spending more of the arc, so raising it lets the amount come back down. 0 is a clothoid and the sane floor: below it the easing shortens and arrives ever more steeply, and at -2 it is a bare corner. When the element is too narrow for the request, both are eased down together so the curvature rate stays put; a square has no flat edge at all and renders as a plain circle.

Algorithm comparison

Left: the shipped worklet, whose join is a power-law spiral — curvature falls from 1/R to 0 as uq−1 along the arc length, a clothoid at q = 2 — with the cap radius solved so the outline fits the box exactly. Right: the same pill with the join built the way CAD tools build a curvature-continuous fillet (SolidWorks and Onshape "curvature continuous", Fusion "G2", Rhino BlendCrv): a polynomial Hermite blend with position, tangent and curvature prescribed at both ends, cubic for G1, quintic for G2, septic for G3, controlled by the setback along each face and a bulge per end. It keeps the cap at its full radius and lets the blend bow outward, which is what a CAD fillet does too — it fits a model, not a bounding box — so a big enough bulge leaves the element. The comb on each cap is curvature (the same graph Rhino's CurvatureGraph and SolidWorks' curvature combs draw); the plot beneath is κ·R against arc length. A step at the arc join is G1 only, a kink is G2, no kink is G3.

Backgrounds, Borders & Shadows

The shape is a mask, so the element keeps its own background and that background gets pill-shaped. A border is set with the pill's own properties — they drive a real border too, which is what shows without the worklet and what reserves the room the drawn ring grows back into. The stadium radius stays under the mask, so native box-shadow: inset and a negative-offset outline just work; only what is painted outside the box needs a wrapper.
